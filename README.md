# Personal Archipelago Development Repository

This fork serves as a personal central repository for development involving core Archipelago (e.g. core contributions, core, etc.).

## Worlds

Worlds developed here exist within their own repository, and are added as gitsubmodules to individualized branches of this repository. Such branches will most often only exist locally and are not push here.
